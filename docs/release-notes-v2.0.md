# V2.0 P0 预览验收

预览使用独立浏览器存储。输入测试片名即可试用。作品按媒体类型和 TMDB ID 识别，每一次观影拥有自己的事件 ID。电影和剧集可使用相同数字 ID。手填同名作品保留独立身份。

1. 在「记一场」输入片名，只填年份并留空评分，保存后检查时间线。
2. 点开记录编辑地点、同行人、感想和评分，刷新后按地点或笔记搜索。
3. 批量选择当前结果，确认数量后移入回收站，在「我的」恢复一场，检查列表和计数。
4. 导出 JSON，在另一个测试浏览器预览并恢复，同一备份再次导入时已有事件会跳过。

## 已运行

- Node 的两组测试覆盖 TMDB 接口行为，以及 1,000 条模拟事件的拆分、重新读入、引用检查和字段保留。
- 无头 Edge 完成新增、仅年日期、编辑、重载、检索、软删除和恢复。检查 320、375、390、768、1024、1440 CSS 像素宽度的时间线，修复 1024px 横向溢出。
- 本地静态构建。复现模型与接口测试可运行 `npm test`，构建可运行 `npm run build`。
