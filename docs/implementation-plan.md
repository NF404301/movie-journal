# V2.0 实施计划

现网使用原生 HTML、CSS 和 JavaScript。Vercel 提供 TMDB 代理；Supabase Auth 和 watch_entries 的按账号行级权限保护云端手记。浏览器版本从 movie-journal-v1 读取扁平数组。现有版本用 revision 检测写入冲突，批量删除会物理删除记录。旧导出包含 records。

P0 保留页面入口、认证与时间线，先在独立预览验证。public 中的模型适配层将每个账号的数据拆为 movies 和 viewings。媒体类型和 TMDB ID 标识已匹配作品，手填记录以旧事件 ID 建立独立作品。旧 id、日期、评分、影评、观看平台和扩展字段原样带入。回收站在事件上记录删除时间。

本地新版使用独立存储键。云端使用独立表以及整份手记的 revision，事务性保存一次操作；该方案适用于私人小型手记。旧表和旧浏览器数据保留作核对。发布前导出原始数据，在本地做迁移预演、比对事件数、引用完整性和导出恢复结果，再确认生产切换。回滚时先停止写入并导出新版含回收站的完整备份，复核切换后的新增、编辑和删除，再恢复旧入口。

预览不复用正式账号。云端验收需要独立的测试 Supabase 项目，或获准创建测试分支。移动端验证覆盖 320 至 1440 CSS px；真机软键盘单列人工验收。P1/P2 待 P0 验收后实施。
