# 观影手记

本项目按 [MIT 许可证](LICENSE) 开源。

以文字和电影海报记录每一次观影。支持按时间浏览、搜索和筛选回忆，记录同行者、观看方式、地点与感想。电影搜索、简介和海报来自 [TMDB](https://www.themoviedb.org/)；搜不到时可以手动填写片名。

## P1 预览

首页可按累计、今年或影院场次进入片库。最近六场、那年今日和随机拾忆来自自己的观影记录。片库支持时间线和海报墙，点海报可浏览同一作品的观看历史，「再看一次」创建独立事件。

在浏览器预览的单场详情中可添加照片或票根、调整顺序和填写说明。图片压缩后保存在当前浏览器的 IndexedDB，JSON 完整备份会携带图片。云端模式需另行验收私有附件存储。预览网址不同会使用不同的本地存储，可通过完整备份转移。

## V2.0 预览

同一作品可以看多次，每一场独立保存日期、评分、地点和感想。快速记录只需片名，日期默认今天，也可以只填年份、月份或选择未知。在「我的 → 回收站」恢复误删记录，在「我的 → 导出我的记录」保存含回收站的完整 JSON 备份。预览与正式站的数据独立。

本次范围、验证结果和待验事项见 [V2.0 验收说明](docs/release-notes-v2.0.md)。

## 当前功能

- 按月浏览电影和剧集，按作品类型、观看方式、片名、人物或地点筛选。
- 记录 5 分制评分、影评和观看日期。批量管理支持选择当前结果和确认删除。
- 选择电影或剧集的 TMDB 搜索结果后自动读取海报和简介。缺少中文简介时尝试英文。直接手填的同名作品分别保留，已有记录可以打开编辑并选择正确版本补齐资料。
- 登录后通过 Supabase 在设备间保存手记，支持导出 JSON 备份。

每次发布用户可见的功能变化，在同一提交中更新本 README 的功能说明。

## 在 Vercel 部署

将此仓库导入 Vercel，使用 `Other` 框架预设；静态文件位于 `public/`，电影搜索接口位于 `api/`。在 Vercel 项目的 Environment Variables 中设置 `TMDB_READ_ACCESS_TOKEN`，值使用 TMDB 的 API Read Access Token。令牌只在服务端使用，不要放入 `public/` 或提交到 Git。部署后检查 `/api/movies/search?q=星际穿越` 与页面的电影搜索。

未配置 Supabase 时，记录保存在当前浏览器。在 Supabase 独立项目按编号顺序执行 supabase/migrations/ 下的 SQL 文件，关闭公开注册，并为自己创建已确认的邮箱账号。在 Vercel 中成对设置 SUPABASE_URL 和 SUPABASE_PUBLISHABLE_KEY（sb_publishable_ 前缀），再重新部署。使用邮箱和密码登录；换设备后使用同一账号。通过“我的 → 导入本机旧手记”可合并同域名的旧记录，保留本地原件。数据库的行级权限按用户隔离记录。

运行 `npm test` 检查电影接口的输入验证、错误处理和简介回退。

电影资料与海报来自 TMDB。本产品使用 TMDB API，但未获 TMDB 认可或认证。
